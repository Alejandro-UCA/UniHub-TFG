================================================================================
          GUÍA PRINCIPAL DE INSTRUCCIONES DE DESPLIEGUE CON DOCKER (PROYECTO RUCT)
================================================================================

El proyecto final ha sido consolidado para ser ejecutado de forma orquestada y
contenerizada mediante DOCKER y DOCKER COMPOSE (Fase 4).

Al levantar el entorno Docker, las Fases 1, 2 y 3 se lanzan simultáneamente.

--------------------------------------------------------------------------------
1. ESTRUCTURA Y SERVICIOS DEL SISTEMA DOCKER
--------------------------------------------------------------------------------
Ubicación de la configuración Docker:  d:\Proyecto\Codigo\Docker\

Servicios integrados en contenedores independientes:
  1. Base de Datos PostgreSQL (ruct_db)  -> Puerto 5432
  2. Rastreador RUCT (ruct_crawler)     -> Programación Cron (0 2 1 * *)
  3. API REST Python / FastAPI (ruct_api)-> Puerto 8000
  4. Portal Web Nginx + React (ruct_www) -> Puerto 80 / 5173

--------------------------------------------------------------------------------
2. REGLA DE PROGRAMACIÓN CRON Y CONCURRENCIA SEGURA (FASE 1)
--------------------------------------------------------------------------------
- **Programación Cron**: El contenedor 'ruct_crawler' ejecuta el rastreo de forma
  automatizada el día 1 de cada mes a las 2:00 AM (regla '0 2 1 * *').
- **Garantía de Concurrencia**: Las escrituras de archivos JSON en la Fase 1 se
  realizan mediante reemplazos atómicos (ficheros .tmp y os.replace). La API REST
  (Fase 2) y el Portal Web (Fase 3) leen los datos sin sufrir lecturas corruptas
  ni bloqueos mientras el crawler está en ejecución.

--------------------------------------------------------------------------------
3. PASO 1: CONSTRUIR Y LEVANTAR TODO EL SISTEMA DOCKER (FASES 1, 2 Y 3)
--------------------------------------------------------------------------------
Paso 3.1: Abrir una consola de comandos en la carpeta de Docker:
  cd d:\Proyecto\Codigo\Docker

Paso 3.2: Ejecutar el comando de construcción y puesta en marcha:
  docker compose up --build -d

  (Este comando iniciará simultáneamente el esquema DDL en PostgreSQL, el
  rastreador con la regla cron, la API REST en FastAPI y el servidor web Nginx).

--------------------------------------------------------------------------------
4. PASO 2: CARGA DE DATOS EN LA BASE DE DATOS POSTGRESQL (ETL)
--------------------------------------------------------------------------------
Para sincronizar las tablas relacionales de PostgreSQL con los JSON extraídos:

  docker compose exec api python database/etl_loader.py

--------------------------------------------------------------------------------
5. RECOLECCIÓN DE MÉTRICAS FÍSICAS DE CONTENEDORES
--------------------------------------------------------------------------------
El sistema mide continuamente la información física de consumo de recursos:
  - Memoria RAM máxima (RSS MB) y porcentaje consumido.
  - Espacio ocupado en disco por volúmenes y archivos JSON/PDF (MB/GB).
  - Uso de CPU (%) e hilos de procesamiento.

Esta información puede consultarse en la API REST ('GET /api/v1/estadisticas/contenedores')
o visualizarse de forma gráfica en el Panel de Administración del Portal Web.

--------------------------------------------------------------------------------
6. ACCESO A LOS SERVICIOS Y CREDENCIALES DEL ADMINISTRADOR
--------------------------------------------------------------------------------
- Portal Web Interactivo (Estilo UCA):  http://localhost   o   http://localhost:5173
- Documentación API REST (Swagger UI):  http://localhost:8000/docs
- Credenciales Administrador de la Web:

    Contraseña:  unihub_super_secret_admin_key_2026

--------------------------------------------------------------------------------
7. APAGADO MANTENIENDO LOS DATOS PERMANENTES
--------------------------------------------------------------------------------
  docker compose down
