Este capítulo trata sobre todos los aspectos relacionados con la implementación en código del sistema \textbf{UniHub}, desglosando la arquitectura técnica de cada una de sus cuatro fases de desarrollo.

\section{Entorno de Construcción}
El marco tecnológico de construcción incluye:
\begin{itemize}
    \item \textbf{Entorno de Desarrollo (IDE):} Visual Studio Code / Antigravity Agent.
    \item \textbf{Lenguajes:} Python 3.12, JavaScript (ES6+ / JSX), SQL (PostgreSQL), HTML5, CSS3.
    \item \textbf{Librerías y Módulos Python:} FastAPI, Uvicorn, SQLAlchemy, Pydantic v2, \texttt{psycopg2-binary}, \texttt{xlrd}, \texttt{BeautifulSoup4}, \texttt{pdfplumber}, \texttt{pypdf}, \texttt{psutil}, \texttt{multiprocessing}, \texttt{concurrent.futures}, \texttt{urllib.robotparser}.
    \item \textbf{Librerías JavaScript:} React 18, Vite 8, Lucide React (iconografía UCA), \texttt{usageTracker} analytics, \texttt{perfTracker} performance telemetry.
    \item \textbf{Control de Versiones y Despliegue:} Git, Docker Engine, Docker Compose v2, Nginx 1.25-alpine.
\end{itemize}

\section{Código Fuente y Estructura Modular}
El código fuente del proyecto se organiza de forma modular bajo el directorio \texttt{Codigo/}:

\subsection{Fase 1: Módulo de Ingesta y Crawler (\texttt{Codigo/Crawler/})}
\begin{itemize}
    \item \texttt{downloader.py}: Implementa el patrón \emph{Circuit Breaker} con tolerancia a fallos de red y método \texttt{reset\_university\_context(univ\_code)} para reiniciar contadores al cambiar de centro. Excluye errores HTTP 404 del contador de sobrecarga y aplica pausas automáticas de 5 minutos con reintento ante errores 429/50x. Cuenta con \emph{fallback} automático HTTP $\rightarrow$ HTTPS, desinfección de esquemas duplicados (\texttt{http://https://}), resolución de dominios autonómicos obsoletos y comprobación de bytes mágicos (\texttt{\%PDF-}) en respuestas con código 200.
    \item \texttt{parsers.py}: Realiza el análisis sintáctico de los archivos del RUCT. Verifica el estado en tiempo real mediante la ficha HTML viva en \texttt{listaestudios}, prioriza universidades públicas, ordena inversamente titulaciones por código de estudio y aplica un filtro estricto de dos capas para descartar planes extinguidos pre-Bolonia (RD 56/2005) seleccionando la publicación BOE más reciente.
    \item \texttt{univ\_web\_crawler.py} (Rescate y Precios Privados - Fase 1 Parte 2): Rastrea los portales web oficiales de las universidades. Analiza archivos \texttt{sitemap.xml} (incluyendo descompresión \texttt{.xml.gz}), verifica el cumplimiento del protocolo de exclusión de robots vía \texttt{urllib.robotparser} y extrae estructuras curriculares de asignaturas en HTML. Asimismo, incorpora la función \texttt{extract\_private\_university\_pricing()} para detectar precios por crédito ECTS e importes anuales en universidades privadas mediante patrones de expresiones regulares.
    \item \texttt{precios\_crawler.py} (Consolidación Tarifaria - Fase 1 Parte 3): Integra los Decretos de precios públicos de las 17 Comunidades Autónomas procedentes de datos oficiales del SIIU y asigna la tarifa por crédito ECTS y la estimación de la primera matrícula anual a 9.783 titulaciones públicas.
    \item \texttt{checkpoint.py}: Gestor atómico del estado del rastreo. Implementa caché en RAM sincronizada por fecha de modificación del disco (\texttt{mtime}), métodos de consulta y marcado atómico como \texttt{is\_extinct\_degree()} y \texttt{mark\_extinct_degree()} para omitir titulaciones extinguidas en 0ms, así como listas persistentes de URLs inalcanzables (\texttt{unreachable\_urls}) y PDFs sin plan desglosado (\texttt{non\_study_plan_pdfs}).
    \item \texttt{main.py}: Orquestador del crawler. Soporta ejecución modular por partes independientes (\texttt{--parts 1 2 3}, \texttt{--parts 2 3} o \texttt{--parts 3}). Para la Parte 1, aplica una arquitectura paralela Productor-Consumidor sobre 2 procesos independientes con descarga multihilo concurrente (\texttt{ThreadPoolExecutor}) de PDFs candidatos y notificación reactiva vía HTTP POST al finalizar (\texttt{trigger\_api\_etl\_sync()}).
\end{itemize}

\subsection{Fase 2: Módulo de API REST y Persistencia (\texttt{Codigo/API/})}
\begin{itemize}
    \item \texttt{database/schema.sql}: Define el esquema relacional en PostgreSQL. Activa la extensión de trigramas \texttt{pg\_trgm} con índices GIN en columnas de búsqueda (\texttt{nombre}, \texttt{titulo}) y crea el rol restringido \texttt{unihub\_api\_user}.
    \item \texttt{connection.py}: Gestiona el conjunto de conexiones SQLAlchemy (\texttt{pool\_size=15}, \texttt{max\_overflow=25}, \texttt{pool\_pre_ping=True}).
    \item \texttt{etl\_loader.py}: Proceso de ingesta de datos JSON hacia la base de datos utilizando \texttt{bulk\_save\_objects} para acelerar las inserciones masivas de asignaturas (reduciendo el tiempo de 15s a menos de 1.5s). Soporta rutas adaptativas tanto en entorno nativo como contenerizado (\texttt{/app/planes\_estudio}).
    \item \texttt{routes/}: Define los controladores REST para universidades (\texttt{universidades.py}), titulaciones y planes (\texttt{titulaciones.py}), métricas de diagnóstico y telemetría cgroup (\texttt{estadisticas.py}) y el endpoint de sincronización en segundo plano (\texttt{POST /api/v1/admin/sync-etl}).
\end{itemize}

\subsection{Fase 3: Módulo de Interfaz Web y Calculadora (\texttt{Codigo/WWW/})}
\begin{itemize}
    \item \texttt{src/services/api.js}: Cliente de comunicación HTTP con la API REST con interceptor de latencias \texttt{perfTracker} y formateo corregido del parámetro de filtrado por Comunidad Autónoma (\texttt{ccaa}).
    \item \texttt{src/components/Navbar.jsx}: Barra de navegación accesible con soporte para menú hamburguesa táctil colapsable en dispositivos móviles y conmutador de modo claro/oscuro.
    \item \texttt{src/components/TuitionCalculator.jsx}: Motor de simulación financiera de matrícula universitaria. Implementa multiplicadores por repetición de asignatura ($1.0\times, 1.5\times, 3.0\times, 4.5\times$), selección rápida por curso, soporte para universidades públicas y privadas, y el sistema completo de exenciones sociales (Beca MEC, Familia Numerosa, Discapacidad $\ge 33\%$, Bonificación 99\% CCAA y Matrícula de Honor).
    \item \texttt{src/components/Geolocation.jsx}: Búsqueda de universidades por distancia Haversine a ciudades de referencia o ubicación GPS con reinicio automático de paginación.
    \item \texttt{src/components/AboutUs.jsx}: Sección informativa ampliada con el desglose técnico de las 4 Fases, datos institucionales del TFG de la UCA y enlaces interactivos a fuentes oficiales.
    \item \texttt{src/components/DegreeCard.jsx} y \texttt{UnivCard.jsx}: Componentes visuales memoizados con soporte de accesibilidad por teclado (\texttt{tabIndex=\{0\}}, eventos de tecla \texttt{Enter}/\texttt{Espacio}) e insignias diferenciadas para precios públicos vs. privados.
    \item \texttt{src/index.css}: Sistema de diseño basado en la identidad corporativa de la Universidad de Cádiz (UCA) con variables CSS, efectos \emph{glassmorphism} y reglas \texttt{@media} para adaptabilidad responsive integral.
\end{itemize}

\section{Código DDL de Base de datos}
El esquema físico en PostgreSQL se construye mediante el archivo DDL \texttt{schema.sql}:
\begin{lstlisting}[language=SQL, caption={Esquema DDL relacional y rol de solo lectura de la API}]
CREATE TABLE IF NOT EXISTS universidades (
    id SERIAL PRIMARY KEY,
    codigo VARCHAR(10) UNIQUE NOT NULL,
    nombre VARCHAR(255) NOT NULL,
    tipo VARCHAR(50),
    comunidad_autonoma VARCHAR(100),
    municipio VARCHAR(100),
    provincia VARCHAR(100),
    web VARCHAR(255),
    email VARCHAR(255),
    telefono VARCHAR(50),
    creado_en TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE IF NOT EXISTS titulaciones (
    id SERIAL PRIMARY KEY,
    codigo_estudio VARCHAR(20) UNIQUE NOT NULL,
    universidad_codigo VARCHAR(10) REFERENCES universidades(codigo),
    titulo VARCHAR(255) NOT NULL,
    nivel_academico VARCHAR(50),
    estado VARCHAR(200),
    precio_credito_ects NUMERIC(10,2),
    precio_estimado_anual NUMERIC(10,2),
    fuente_precio VARCHAR(100),
    creado_en TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Rol de solo lectura para la API REST
CREATE ROLE unihub_api_user WITH LOGIN PASSWORD 'unihub_api_password_sec2026';
GRANT CONNECT ON DATABASE unihub_db TO unihub_api_user;
GRANT SELECT ON ALL TABLES IN SCHEMA public TO unihub_api_user;
\end{lstlisting}
